# 🧭 Rehatin — Informasi Hangout & Wisata Jabodetabek

Rehatin adalah aplikasi web full-stack yang menyediakan informasi lengkap, ringkas, dan terpercaya mengenai tempat wisata serta hangout di wilayah Jabodetabek (Jakarta, Bogor, Depok, Tangerang, Bekasi) & Bandung. Website ini dirancang untuk membantu pengguna menemukan tempat yang cocok untuk berkumpul, bersantai, atau berwisata sesuai kategori dan lokasi. Aplikasi ini dibangun menggunakan **React.js untuk frontend** dan **Express.js untuk backend**.

---

## ✨ Fitur Utama

- Daftar tempat wisata dan hangout di Jabodetabek  
- Fitur pencarian berdasarkan nama tempat  
- Filter berdasarkan kategori (kuliner, taman, museum, rekreasi, dll.)  
- Halaman detail yang berisi deskripsi, maps, ulasan, hingga estimasi harga  
- Responsive Design (mobile & desktop friendly)

---

## 🚀 Cara Menjalankan Project

1. Clone repository ini:
   ```bash
   git clone https://github.com/MaulanaHidayatulloh/Rehatin.git
2. Impor database, gunakan file rehatin.sql untuk membuat database dan tabel yang diperlukan
3. Install Dependencies:
- Frontend
  ```bash
  cd frontend
  npm install
- Backend
  ```bash
  cd backend
  npm install
4. Jalankan Aplikasi
- Jalankan Backend
  ```bash
  npm run server:dev
- Jalankan Frontend
  ```bash
  npm run dev
